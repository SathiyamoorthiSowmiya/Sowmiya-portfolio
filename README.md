# Sowmiya S — Portfolio

Personal portfolio website of Sowmiya S, a MERN Stack Developer, built to showcase skills, projects, certifications and contact details to recruiters and collaborators.

**Live site:** https://sowmiyasportfolio.netlify.app/

## Sections

- **About** — background, professional photo and a short summary
- **Resume** — downloadable resume (PDF/Word)
- **Skills** — technical (Frontend, Backend, Database, Tools) and soft skills
- **Projects** — featured full-stack MERN and frontend projects with live demo, frontend/backend repo links
- **Certifications** — filterable certificate gallery with a click-to-zoom lightbox
- **Contact** — working contact form and social links (LinkedIn, GitHub, Email)
